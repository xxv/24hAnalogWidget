24h Analog Clock Widget and Android Wear Face
=============================================

This is a homescreen widget and Android Wear watch face that displays a 12-at-the-top 24 hour analog
clock. Noon is at the top, so that the hour hand mimics the path of the sun.

![screenshot of widget](extra/sshot02.png)

![screenshot of the Wear OS watch face](extra/wear_face.png)
![the same watch face in always-on mode](extra/wear_face_ambient.png)

In addition to the time, it will display when the sun rises/sets for your
current location on the dial.

If you like, you can easily install [The homescreen widget][play] or [The Android Wear
face][playwear] from Google Play.

The Wear OS watch face is built with the Watch Face Format, which can't contain
code, so the sunrise/sunset times come from a small companion app that publishes
them as complications.

Permissions
-----------

The sunrise/sunset feature uses the approximate location permission. A fresh
location is only requested while one of the apps is open; the rest of the time
they reuse the location the system already has, which doesn't power up any
location hardware. Nothing leaves your device. See [PRIVACY.md](PRIVACY.md).

Modules
-------

| Module        | What it is                                                     |
| ------------- | -------------------------------------------------------------- |
| `phoneWidget` | the home screen widget for phones                               |
| `wear`        | the Wear OS watch face (Watch Face Format; resources only)      |
| `sun`         | Wear OS app publishing sun times as complications for the face  |
| `lib`         | the shared clock view and dial overlays                         |

The watch face dial is generated by `extra/generate_dial.py`, which writes it
into `wear/src/main/res/raw/watchface.xml`. Edit the script, not the generated
part of the XML.

Building
--------

    ./gradlew assembleDebug    # all three apps
    ./gradlew test lintDebug   # unit tests and lint

Source
------

The widget's sunrise/sunset times come from
[jSunTimes](http://www.jstott.me.uk/jsuntimes/), included in the source tree in
both byte-compiled form as well as source. The Wear OS companion app computes
its own times with the NOAA solar equations (`sun/.../SolarCalculator.java`).

The watch face bundles DejaVu Sans Mono for the dial; see
`wear/DEJAVU_FONT_LICENSE.txt`.

The full source is available at
[git://staticfree.info/git/24hAnalogWidget](git://staticfree.info/git/24hAnalogWidget).
See the [project page](http://staticfree.info/projects/24h_clock/) for more
info.
